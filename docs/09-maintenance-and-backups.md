# Maintenance and Backups

## Routine Maintenance
- Review application and server logs.
- Apply security updates after testing.
- Check forms and important public pages.
- Monitor disk space and upload directories.
- Review administrator accounts and permissions.

## Backups
- Back up the database.
- Back up application files and uploaded media.
- Store backups separately from the production server.
- Periodically test restoration.

## Changes
Test updates locally before production deployment.
Record significant changes in the changelog.
