# Security Guidelines

- Use CodeIgniter's CSRF protection.
- Validate and sanitise incoming data.
- Escape output in views.
- Use password hashing through the authentication framework.
- Enforce authentication and role-based authorisation.
- Apply rate limits and spam protection to public forms.
- Restrict file uploads by type, size and storage location.
- Keep secrets outside public web access and out of Git.
- Use HTTPS in production.
- Maintain backups and review application logs.
- Avoid collecting sensitive information that is not necessary.
- Record important administrative actions where appropriate.
