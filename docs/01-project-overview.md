# Project Overview

## Purpose
Build a professional, responsive website and manageable CMS for Membley
Security Group.

## Main Business Areas
- College and training services
- Security services
- Group information and corporate communications

## Main Objectives
- Present the organisation professionally.
- Make courses and services easy to discover.
- Allow visitors to submit applications and enquiries.
- Allow authorised administrators to manage website content.
- Support future growth without requiring code changes for routine publishing.

## Design Direction
Initial design direction: navy blue, gold and white.
Final brand colours and logo treatment will be confirmed using the client's logo.

## Delivery Approach
Develop locally, test, document and deploy to the client's cPanel hosting.
